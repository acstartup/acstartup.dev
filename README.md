# 💻 acstartup.dev

My personal portfolio website repository built with HTML & Tailwind CSS showcasing projects, experience, and contact information.

Check out the website at [acstartup.dev](https://acstartup.dev)!

### Local Installation & Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/acstartup/acstartup.dev.git
   cd acstartup.dev
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run development server**
   ```bash
   npm run dev
   ```
   This will start Tailwind CSS in watch mode, automatically rebuilding styles when you make changes.

4. **Open in browser**
   - Open `index.html` in your web browser
   - Or use a local server like Live Server (VS Code extension)
